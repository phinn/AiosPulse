How it works

工作方式

工作方式

仕組み

  1. Create a read-only API key in App Store Connect (Users and Access → Integrations → App Store Connect API).
  2. 在 App Store Connect 创建只读 API Key(用户和访问 → 集成 → App Store Connect API)。
  3. 在 App Store Connect 建立唯讀 API Key(使用者和存取 → 整合 → App Store Connect API)。
  4. App Store Connect で読み取り専用 API キーを作成(ユーザとアクセス → 統合)。
  5. Paste the key once — it is stored in your Mac's Keychain, and sync runs on demand or on your own schedule.
  6. 粘贴一次即可 —— Key 存进你的 Mac 钥匙串,按需或按你自己的节奏同步。
  7. 貼上一次即可 —— Key 存進你的 Mac 鑰匙圈,按需或按你自己的節奏同步。
  8. キーを一度貼るだけ —— Mac のキーチェーンに保存され、必要時に同期。
  9. Open the app: today's briefing, diagnostics and action items are already there.
  10. 打开 App:今日简报、诊断和行动项已经在那里等你。
  11. 打開 App:今日簡報、診斷和行動項已經在那裡等你。
  12. アプリを開けば、今日のブリーフィング・診断・アクションは既にそこに。

Privacy

隐私

隱私

プライバシー

AiosPulse runs entirely on your Mac. Your API key lives in the macOS Keychain, your analytics data never leaves your disk, and there is no account, no telemetry and no third-party analytics SDK. The optional AI feature talks only to the LLM provider you configure. Read the full Privacy Policy.
